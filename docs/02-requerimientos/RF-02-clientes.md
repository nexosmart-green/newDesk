# RF-02 Clientes

| ID | Requerimiento | Prio |
|---|---|---|
| RF-02.01 | ABM de clientes: razón social, nombre comercial, CUIT, contacto (nombre, email, teléfono), notas, estado activo/inactivo. | M |
| RF-02.02 | Ficha del cliente: proyectos, horas vendidas vs consumidas totales. | M |
| RF-02.03 | Contactos múltiples por cliente. | C |
| RF-02.04 | Acceso del cliente al portal: estado de sus proyectos y reportes de problemas (RF-13.07/08, código por mail). Ver avance y horas: C. | M (estado) / C (avance) |

- **CA-02.01** Un cliente con proyectos no se borra: se inactiva. Un cliente inactivo no aparece al crear proyectos nuevos.
