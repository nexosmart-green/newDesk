# Mis horas: ver y corregir todos mis registros

- Pidió: el usuario (dev violet)
- Fecha: 2026-11-10
- Prioridad: alta

## Pedido original

> tenemos que tener algun apartado donde podamos ver todos los registros de tiempo que tenemos y debemos poder editarlos cuando queramos. obviamente muestra los propios

## Respuestas del usuario

- Se mantiene el límite de días para corregir (7 por defecto, configurable): las más viejas se ven con candado y "pedile a un administrador".
- Corregir también cambia la tarea y el proyecto: mueve las horas de una bolsa a otra; si en la destino no entran, no deja.
- Cada persona borra las suyas, con el mismo límite de días.
- El admin usa la misma pantalla con un filtro por persona.
